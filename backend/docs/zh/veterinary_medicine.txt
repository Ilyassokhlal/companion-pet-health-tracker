獸醫學（英語：veterinary medicine 或 veterinary science）是一門應用醫學診斷與治療方法來處理動物問題的學門，面對的動物包括寵物、野生動物或家畜與家禽等。獸醫學除了研究一般醫學問題之外，也關注於動物的行為。受過獸醫學訓練並以此來診療動物的醫生稱為獸醫或獸醫師。

兽医学
兽医学是一门古老的学科。由于一些先进的诊断和治疗技术的出现，兽医学在近年来得到了很大的发展。现在的动物已经可以使用一些先进的方法进行治疗，如注射胰岛素、根管治疗术、髋关节置换术、白内障手术、人工心脏起搏器等牙科或外科的治疗。

兽医学 - 学科分类
兽医专业近年来发展也很快。美国兽医协会（AVMA）目前已经承认了20个兽医学科，包括麻醉学、动物行为学、皮肤病学、急救学、内科学、心脏内科、肿瘤学、神经学、影像诊断学和外科学。在美国，兽医从兽医学校毕业后如果要从事专业工作，需经过实习医师期和住院医师实习期后经过严格考试才能胜任。

兽医学 - 工作领域
兽医学通过监测家畜、宠物和野生动物的健康情况，对保卫人类的生命安全也做出了贡献。由于全球范围不断出现的动物传染病也要求兽医学通过群体诊断学的方法对流行病和传染病进行有效控制。

兽医学 - 工作领域
通过维护动物健康和对肉类进行检疫，兽医也会参加相关工作来确保食品数量、质量和安全。兽医学家在生物学、化学、农学及药物学方面都占有重要地位。

兽医学 - 工作领域
在一些国家，马兽医学也是一个专门的领域。对马的临床工作主要包括运动系统、整形外科、消化道紊乱（包括马腹痛，这是家马死亡的主要原因）和呼吸道感染等疾病。

兽医学 - 工作领域
动物医学也包括了动物园动物和野生动物的治疗，这部分工作在近年来也越来越重要和复杂。而野生动物的保护也越来越紧急。

兽医学 - 美国的兽医领域
和人类健康领域一样，兽医学在实践中也需要大量的人来满足病患的需要。兽医需要在兽医学校学习4年后，还要完成3-4年的大学的准兽医工作。接下来，他们需要在想获得执业许可的州参加考试。一般认为，兽医学校是各种医学专业中最难被接受的。事实上，在医生中，兽医通常被列为最聪明且最可信赖的。他们需要诊断各种不同的动物，却无法同病人进行交流。除了兽医外，很多兽医院还提供兽医技师和兽医助手给生病动物与健康动物一样的照护。兽医技师实际上就是兽医护士，他们从两年或四年学院学习后并获得合法认证。兽医技师需要在兽医执行治疗时进行相应的辅助。兽医助手在很多州并不需要执照，但也要通过各类技术学校的良好培训后才能参加工作。

兽医学
兽医学是医学的一个分支，涉及非人类动物的疾病、失调和损伤的预防、管理、诊断和治疗。其范围很广，涵盖所有动物物种，包括家养和野生动物，以及可能影响不同物种的各种病症。

兽医学
兽医学的实践既有在专业监督下进行的，也有在没有专业监督的情况下进行的。专业护理最常由兽医师（也称兽医、兽医外科医生或“vet”）主导，但也由兽医辅助人员提供，包括兽医护士、兽医技术员和兽医助理。其他辅助专业人员可能承担专门的角色，例如动物物理治疗或牙科，以及与特定物种相关的角色，例如蹄铁匠。

兽医学
兽医科学通过监测和控制人兽共患病（从非人类动物传播给人类的传染病）、保障食品安全，以及通过医学研究在人类身上的应用来促进人类健康。兽医还通过监测和治疗家畜健康来帮助维持食物供应，并通过让宠物保持健康长寿来促进人们的心理健康。根据工作类型的不同，兽医科学家常与流行病学家和其他卫生或自然科学家合作。在伦理上，兽医通常有义务关注动物福利。兽医负责诊断、治疗动物，并帮助动物保持安全和健康。

兽医学 - 职业的建立
1762年，克劳德·布尔热拉在法国里昂创办了第一所兽医学校。据Lupton所述，布尔热拉目睹牛瘟对法国畜群造成的破坏后，便投入时间寻找治疗方法。这促使他于1761年在里昂创办了一所兽医学校，并从这所学校派遣学生去防治这种疾病；在很短的时间内，借助兽医科学与技艺对农业的帮助，瘟疫得到遏制，牲畜恢复了健康。这所学校在18世纪立即获得国际认可，其教学模式借鉴了人类医学、博物学和比较解剖学等已有领域。

兽医学 - 职业的建立
瑞典的兽医教育于1774年获得资助，并于1775年5月8日国王古斯塔夫三世签署文件后正式开始。

兽医学 - 职业的建立
彼得·赫恩奎斯特（Peter Hernquist）曾在乌普萨拉师从卡尔·冯·林奈，也曾在里昂师从克劳德·布尔热拉，他担任校长，被视为瑞典兽医学之父。

兽医学 - 职业的建立
奥迪厄姆农业协会于1783年在英格兰成立，旨在促进农业和工业，在英国兽医职业的创立中发挥了重要作用。创始成员托马斯·伯吉斯开始投身动物福利事业，倡导更人道地对待患病动物。1785年的一次协会会议决定“以理性的科学原则推动蹄铁术的研究”。

兽医学 - 职业的建立
医生詹姆斯·克拉克撰写了一篇题为《疾病的预防》的论文，主张兽医行业专业化并建立兽医学院。这一目标最终于1790年实现，这得益于格兰维尔·佩恩的倡导，他说服法国人伯努瓦·维亚尔·德·圣贝尔接受伦敦新成立的兽医学院的教授职位。皇家兽医外科医师学院于1844年根据皇家特许状成立。兽医科学在19世纪末走向成熟，约翰·麦克法迪恩爵士对此作出了显著贡献，许多人认为他是现代兽医研究的奠基人。

兽医学 - 职业的建立
在美国，第一批学校于19世纪初在波士顿、纽约市和费城建立。1879年，爱荷华农学院成为第一所设立兽医学院的赠地学院。

兽医学 - 职业的建立
1920年代和1930年代，汽车取代马匹成为个人出行的主要方式，美国兽医行业经历了一次重大转型。城市中的马科兽医被迫创新，将业务重心转向伴侣动物，即狗和猫。

兽医学 - 兽医师
兽医护理和管理通常由获得兽医学博士学位的兽医师（通常称为兽医、兽医外科医生或“vet”）主导。这一角色相当于人类医学中的内科医生或外科医生（医学博士），需要进行研究生阶段的学习并取得资格。

兽医学 - 兽医师
大多数兽医在临床环境中工作，直接治疗动物。他们可能从事全科诊疗，治疗各种类型的动物；可能专门诊治某一类动物，如伴侣动物、家畜、实验动物、动物园动物或马；也可能专攻某一狭窄的医学学科，如兽医外科、皮肤病学、心脏病学、神经病学、实验动物医学、内科等。

兽医学 - 兽医师
作为医疗卫生专业人员，兽医在照护患病动物时面临伦理抉择。目前行业内的争论包括对动物实施纯粹美容性手术的兽医伦理问题，例如给猫去爪，以及给狗断尾、剪耳和去声带。

兽医学 - 兽医师
各种类型的动物都会接受多种多样的外科手术，但并非所有手术都由兽医实施。例如在伊朗的一个案例中，一名眼科医生在世界上首次成功为一只公鸡实施了白内障手术。

兽医学 - 兽医辅助人员
兽医辅助人员，包括兽医护士、兽医技术员和兽医助理，或协助兽医工作，或根据自身技能和资格在自己的执业范围内工作，在某些情况下还包括实施小手术。

兽医学 - 兽医辅助人员
在全球范围内，兽医辅助人员的角色不如兽医那样统一，其资格水平和相应的技能组合差异很大。

兽医学 - 兽医辅助人员
兽医学范围内存在许多职业，但这些职业不一定由兽医或兽医护士来从事。其中包括在人类医学中也存在的角色，例如处理肌肉骨骼疾病的从业者，包括整骨师、脊椎按摩师和物理治疗师。

兽医学 - 兽医辅助人员
汽车的出现对兽医行业产生了巨大影响。有了汽车，兽医现在可以拥有流动诊所，开车去帮助有需要的动物。由于大型动物运输困难，这对大型动物兽医（通常专门诊治较大的动物）极为有利。也有小型动物兽医（通常专门诊治较小的动物）同样是流动兽医，但这在大型动物兽医中更为常见。成为流动兽医的好处很多，因为这使兽医无需实体场所就能拥有诊所和业务。
