狗的健康
狗的健康是从整体上来看待的；它涵盖许多不同方面，例如疾病过程、遗传和营养健康。影响狗的传染病之所以重要，不仅是从兽医的角度出发，也是因为它们对公共卫生构成风险；狂犬病就是一个例子。遗传性疾病也会影响狗，这往往是为培育特定犬种而进行选择性繁育的结果。由于市售狗粮和自制狗粮都很流行，营养也是一个被广泛研究的课题。

狗的健康 - 疾病
有些疾病和其他健康问题是人和狗共有的；另一些则是狗和其他动物特有的。狗易患多种疾病；与人类相似，它们也可能患糖尿病、癫痫、癌症或关节炎。

狗的健康 - 疾病
传染病是由病毒、细菌、真菌或寄生虫（动物性或原生动物性）等生物引起的。这些疾病大多直接在狗与狗之间传播，另一些则需要蜱或蚊子等媒介。从公共卫生角度看，某些传染病值得关注，因为它们是人兽共患病（可以传染给人类）

狗的健康 - 细菌性疾病
狗的细菌性疾病通常不会在狗与狗之间传染；它们通常是伤口定植、抵抗力下降后继发的机会性感染（往往由病毒感染导致），或继发于其他疾病（如继发于皮肤过敏的脓皮病，或继发于囊性子宫内膜增生的子宫积脓）的结果。这些例子不被视为传染病，因为它们不符合科赫法则——例如，中间葡萄球菌是从狗皮肤感染中常分离出的一种细菌，但把它引入健康的狗身上并不会引起脓皮病。这种细菌很可能本来就存在于健康狗的皮肤上。

狗的健康 - 细菌性疾病
有些细菌会在狗与狗之间传染。其中最值得注意的是：引起犬舍咳的病原之一支气管败血波氏杆菌、引起钩端螺旋体病的钩端螺旋体属细菌（Leptospira sp），以及引起犬布鲁氏菌病的犬布鲁氏菌（Brucella canis）。还有一些常见的蜱传细菌性疾病，包括莱姆病、埃立克体病和落基山斑疹热。

狗的健康 - 细菌性疾病
钩端螺旋体病是由钩端螺旋体属细菌引起的一种人兽共患病。人和狗通过接触含有受感染动物尿液的水、食物或土壤而被感染。这可能通过吞下被污染的食物或水而发生，也可能通过皮肤接触发生，尤其是眼睛或鼻子等黏膜表面或破损的皮肤。在狗身上，最常见的传播途径是饮用被松鼠或浣熊等受感染野生动物尿液污染的水坑、池塘或沟渠里的水。钩端螺旋体病最常损害肝脏和肾脏。可能发生血管炎，引起水肿，并可能导致弥散性血管内凝血（DIC）。心肌炎、心包炎、脑膜炎和葡萄膜炎也是可能的后遗症。

狗的健康 - 细菌性疾病
狗的布鲁氏菌病由犬布鲁氏菌（Brucella canis）引起。它是一种性传播疾病，但也可以通过接触流产的胎儿传播。最常见的症状是妊娠最后三个月流产或死产。其他症状包括椎间盘和眼睛发炎（葡萄膜炎），公犬还会出现睾丸炎和前列腺炎。

狗的健康 - 细菌性疾病
蜱传疾病在狗身上很常见。莱姆病又称疏螺旋体病，由伯氏疏螺旋体（Borrelia burgdorferi）引起，在美国西海岸由太平洋硬蜱（Ixodes pacificus）传播，在美国其他地区由肩突硬蜱（I. scapularis，即鹿蜱）传播。体征和症状包括发热、关节肿痛、跛行和淋巴结肿大。美国本土全部48个州都在狗身上诊断出过这种病。引起犬埃立克体病的犬埃立克体（Ehrlichia canis）和引起落基山斑疹热的立氏立克次体（Rickettsia rickettsii），都由美洲犬蜱（Dermacentor variabilis）和褐色犬蜱（Rhipicephalus sanguineous）传播。

狗的健康 - 细菌性疾病
狗最常见的真菌性疾病之一是癣病，即皮肤癣菌病，这是一种皮肤、毛发或指甲的感染。引起狗癣病的真菌有三种。约70%的感染由犬小孢子菌（Microsporum canis）引起，20%由石膏样小孢子菌（M. gypseum）引起，10%由须癣毛癣菌（Trichophyton mentagrophytes）引起。症状包括脱毛和皮肤脱屑。局部癣病不一定需要治疗，因为这种病有自限性，但外用咪康唑或克霉唑可以缩短病程。全身性感染最常见于免疫功能低下的狗，可以用灰黄霉素或伊曲康唑等口服抗真菌药物治疗。感染可以传给人。

狗的健康 - 细菌性疾病
有几种真菌性疾病是全身性的，也就是说会影响多个身体系统。芽生菌病由芽生菌属（包括皮炎芽生菌）引起，是一种人和狗都会感染的真菌病。它通过吸入真菌孢子传播，主要见于美国密西西比河和五大湖地区。在加拿大的四个省份——萨斯喀彻温、马尼托巴、安大略和魁北克——也有病例报告。症状包括体重下降、咳嗽、发热、淋巴结肿大、皮肤病变流脓、眼部发炎伴分泌物、失明和跛行。由于狗从环境中受到感染的可能性是人的十倍，它们被视为这种疾病的哨兵动物。治疗需要至少60–90天的口服抗真菌药物疗程，严重病例需静脉注射抗真菌药物。

狗的健康 - 细菌性疾病
组织胞浆菌病由荚膜组织胞浆菌（Histoplasma capsulatum）引起，是一种分布于全世界的疾病。在美国，它主要见于密西西比河和俄亥俄河地区，最常存在于鸟类和蝙蝠的粪便中。症状包括体重下降、咳嗽、发热、淋巴结肿大和胃肠道症状。球孢子菌病由粗球孢子菌（Coccidioides immitis）引起，见于中美洲和南美洲、墨西哥以及美国西南部的干旱和半干旱地区。症状包括体重下降、发热、咳嗽、淋巴结肿大和跛行。

狗的健康 - 细菌性疾病
兽医寄生虫学研究动物体外和体内的寄生虫。跳蚤、螨虫、蜱和蚊子等体外寄生虫会引起皮肤刺激，而且往往还携带其他疾病或体内寄生虫。

狗的健康 - 细菌性疾病
狗可能会染上各种跳蚤和蜱并把它们带回家，这些寄生虫在家中繁殖并叮咬人（反之亦然）。如今蜱传的莱姆病已在大片地区成为地方性流行病，另外还有落基山斑疹热等其他类似疾病，因此这两种寄生虫特别值得注意。虽然狗似乎不像人那样容易患上这类疾病，但类似的立克次体病曾经由狗传给人，例如一只狗咬死了一只受感染的兔子，然后在屋里离主人很近的地方抖动身体，导致全家大部分人受到致命感染。

狗的健康 - 细菌性疾病
虱子侵扰（虱病）会引起剧烈瘙痒、抓挠和脱毛。感染狗的两种咀嚼虱是犬啮毛虱（Trichodectes canis）和Heterodoxus spiniger。犬吸虱是棘颚虱（Linognathus setosus）。

狗的健康 - 体内寄生虫
寄生虫，特别是钩虫、绦虫和蛔虫等肠道蠕虫，可以通过狗的粪便传播。有些绦虫以跳蚤为中间宿主：蠕虫卵必须被跳蚤吃下才能孵化，然后受感染的跳蚤必须被吞食（通常是狗在理毛时吞下，但偶尔也会通过各种途径被人吞下），成虫才能在肠道中定居。蠕虫的卵随后随粪便排出，循环再次开始。肠道蠕虫会引起不同程度的不适。

狗的健康 - 体内寄生虫
心丝虫是狗的一种拟寄生物。它很难清除，而且可能致命；不过，用药物很容易预防。顾名思义，受感染的蚊子将幼虫注入狗的皮肤，幼虫移行到循环系统，在肺动脉和心脏中定居，并以惊人的程度生长繁殖。对狗的影响可想而知：心力衰竭导致死亡。治疗受感染的狗很困难，需要尝试用砷化合物毒杀健康的虫体，同时又不能毒死已经虚弱的狗，而且可能不会成功。建议使用心丝虫预防药进行预防，这类药物含有一种化合物，能在感染时立即杀死幼虫而不伤害狗。它们常与其他寄生虫预防药合用。

狗的健康 - 体内寄生虫
棘球蚴病由绦虫棘球绦虫属（Echinococcus）引起，见于狗、野生犬科动物、狐狸等。由于它作为人兽共患病的重要性，预防和治疗至关重要。预防棘球蚴病比治疗更容易。吡喹酮等驱虫药可能有助于预防这种疾病。禁止喂食未煮熟的动物内脏可能是预防这类绦虫的最佳措施。

狗的健康 - 遗传病
遗传病是一些狗，特别是纯种狗的问题。因此，许多国家的养犬俱乐部规定，患有某些遗传病或被认为是携带者的狗不能登记注册。一些最常见的疾病包括：见于大型犬的髋关节发育不良；在杜宾犬中遗传的血管性血友病，这是一种影响血小板的疾病；见于沙皮犬和许多其他品种的睑内翻，即眼睑向内卷曲；在许多品种中遗传的进行性视网膜萎缩；已知在比利时牧羊犬、德国牧羊犬、可卡犬和圣伯纳犬中遗传的耳聋和癫痫。

狗的健康 - 遗传病
主动脉瓣下狭窄（SAS）是一种遗传病，会使心脏与主动脉之间的血流通道变窄。这会导致心脏问题，有时导致猝死。它影响纽芬兰犬和金毛寻回犬等较大的品种。在某些狗（如柯利犬）身上，蓝陨石色或丑角色毛色实际上是一种部分隐性基因的杂合子，该基因会妨碍神经系统正常发育；因此，如果两只这样的狗交配，平均会有四分之一的幼犬在神经系统和感觉器官方面有严重的遗传缺陷，从耳聋到致命缺陷不等。

狗的健康 - 皮肤病
皮肤病在狗身上非常常见。特应性皮炎是一种慢性过敏性疾病，据认为影响多达10%的狗。其他与过敏有关的皮肤病包括急性湿性皮炎（热点）和脓皮病（两者的特征都是继发细菌感染）、食物过敏、耳部感染和跳蚤过敏性皮炎。犬毛囊发育不良是一种毛囊遗传病，会导致脱毛（秃毛）。疥癣是由螨虫引起的传染性皮肤病。甲状腺功能减退症和库欣综合征等内分泌疾病也可能表现为脱毛或反复细菌感染等皮肤问题。另一类体表疾病是水囊瘤，通常是肘关节上或附近的肿胀。营养也可能在皮肤病中起作用，因为某些营养素缺乏可能导致皮肤脱屑、发红、出油、秃毛和/或瘙痒。（关于影响皮肤的具体营养素，参见“狗的皮肤病”）

狗的健康 - 皮肤病
某些犬种的身体特征，如皮肤褶皱或皮褶过多，也会影响个体对皮肤问题的易感性。例如，皮褶皮炎是一种皮肤感染，在斗牛犬、可卡犬和英国史宾格犬等品种中更为常见。

狗的健康 - 皮肤病
狗的骨科疾病可能是发育性、遗传性、外伤性或退行性的。由于狗活泼好动，受伤很常见。最常见的损伤之一是前十字韧带损伤，这种情况常常需要手术。户外活动的狗因被汽车撞击等外伤而骨折很常见。退行性关节病在老年犬中很常见，是开具非甾体抗炎药最常见的原因之一。

狗的健康 - 皮肤病
遗传性骨科疾病主要见于纯种狗。髋关节发育不良是一种常见问题，主要影响较大的品种。髋关节发育不良是髋关节形状的缺陷，根据髋关节脱位程度的不同，随着狗年龄增长可能会相当疼痛。随着时间推移，它常常导致髋关节炎。肘关节也可能发生发育不良。髌骨脱位可能是小型犬的问题，可导致后腿跛行和疼痛。

狗的健康 - 皮肤病
发育性骨科疾病包括全骨炎和肥大性骨营养不良。全骨炎发生于大型和巨型犬，通常在五到十四月龄之间，表现为发热、疼痛和游走性腿部跛行。肥大性骨营养不良也见于年轻的大型和巨型犬，特征是疼痛、跛行、发热和长骨干骺端肿胀。

狗的健康 - 肿瘤与癌症
狗身上既有良性肿瘤，也有恶性肿瘤。常见的良性肿瘤包括脂肪瘤、非病毒性乳头状瘤、皮脂腺腺瘤和肛周腺腺瘤。

狗的健康 - 肿瘤与癌症
常见的癌症包括淋巴瘤、黑色素瘤、肥大细胞瘤（尽管其表现可能是良性的，但被视为具有潜在恶性）和骨肉瘤（骨癌）。

狗的健康 - 肿瘤与癌症
某些品种更容易患特定的肿瘤，尤其是较大的品种。金毛寻回犬特别容易患淋巴瘤，一生中的患病风险为1/8。拳师犬和巴哥犬易患多发性肥大细胞瘤。苏格兰㹴患移行细胞癌（一种膀胱癌）的风险是混种犬的十八倍。

狗的健康 - 肿瘤与癌症
由于狗什么都吃，胃肠道不适在狗身上很常见。最常见的症状是厌食、呕吐和腹泻。吞食异物可导致胃肠道急性梗阻，这是一种非常危险的情况。饮食不当也可能导致急性胰腺炎。

狗的健康 - 胃胀气与胃扭转
胃扩张扭转，即胃扭转和胃胀气，主要影响胸部深而窄的品种，如大丹犬、圣伯纳犬、德国牧羊犬、标准贵宾犬和爱尔兰雪达犬。胃在其支持韧带上发生扭转，封闭了出口，胃内容物开始产生气体压力，引起剧烈疼痛，并迅速导致休克和大面积胃组织坏死。它可在几小时内致命。发生过胃胀气的狗很容易复发。治疗包括稳定病情，并进行腹部手术将狗的胃固定住以防复发（胃固定术）。

狗的健康 - 眼病
眼病在狗身上很常见。狗会患白内障、犬青光眼和睑内翻。狗特有的眼病包括进行性视网膜萎缩、柯利眼异常、突发性后天视网膜变性和樱桃眼。眼部受伤可导致角膜溃疡。

狗的健康 - 眼病
纯种狗中具有遗传基础的双侧青光眼发病率高于除人类以外的任何物种。狗的白内障要么有遗传基础，要么也可能由糖尿病引起。核硬化看起来像白内障，但实际上是一种正常的年龄相关变化。

狗的健康 - 眼病
前庭疾病的症状包括头部倾斜、转圈、眼球震颤（眼球的异常运动），以及站立困难或无法站立。这些临床症状与人类眩晕时的症状相似。前庭疾病可能有多种病因。老年犬易患一种特发性（即病因不明的）前庭疾病，俗称“老年犬前庭疾病”，即特发性外周前庭疾病。症状可能很快改善，也可能需要几天。较少见的是，前庭症状也可能由内耳疾病、脑肿瘤、中风或其他原因引起。特发性外周前庭疾病的主要风险在于，狗常常无法进食、饮水或到户外排尿排便。这些病例必须接受静脉输液和营养支持治疗；由于这种经历可能让狗非常紧张，有时还会给予轻度镇静剂。

狗的健康 - 眼病
年龄较大的小型犬容易因二尖瓣退化而发生充血性心力衰竭。已知这种疾病在骑士查理王小猎犬中遗传。退行性瓣膜病是狗最常见的心脏病。二尖瓣反流导致血流紊乱和左心房压力升高。这会使肺血管压力升高并引起肺水肿（肺部积液）。左心室输出的血液减少，使身体通过提高交感神经张力和激活肾素–血管紧张素–醛固酮系统（RAAS）来代偿。交感神经张力升高会导致外周血管阻力增加、心率加快和心肌收缩力增强。交感神经张力长期升高会损伤心肌。RAAS的激活会使肾脏潴留更多的水和钠，使血管收缩，并产生其他使血容量增加的作用。它还会使舒张压升高，导致肺水肿。过去，充血性心力衰竭的治疗主要依靠两类针对这些问题的药物：减少血容量的利尿剂（尤其是呋塞米），以及阻断RAAS的ACE抑制剂。最近，匹莫苯丹——它能增强心肌收缩的力量，同时也是一种血管扩张剂——被越来越广泛地用于治疗瓣膜病引起的充血性心力衰竭。2008年9月发表的一项名为QUEST研究（生活质量与生存时间延长研究）的大型兽医研究发现，接受匹莫苯丹加呋塞米治疗的充血性心力衰竭犬，其生存结果明显优于接受贝那普利（一种ACE抑制剂）加呋塞米治疗的犬。不过，ACE抑制剂和匹莫苯丹的作用机制不同，许多兽医心脏病专家建议同时使用。在过去十年里，已开发出一种修复二尖瓣的新手术技术，用聚四氟乙烯（PTFE）假体替换或加固二尖瓣腱索，并收紧二尖瓣环，以减少或消除反流。

狗的健康 - 眼病
心肌病，即心肌的疾病，也见于狗，且与大型犬有关（例外是中型犬可卡犬）。扩张型心肌病见于大丹犬、爱尔兰猎狼犬、圣伯纳犬、杜宾犬、拳师犬和其他大型犬。杜宾犬除了心肌衰竭外，还容易发生室性心律失常。拳师犬易患一种独特的心肌病，其临床和组织学变化与人类致心律失常性右心室心肌病（ARVC）相似。这种疾病被称为“拳师犬心肌病”或“拳师犬ARVC”，其特征是出现室性快速性心律失常。患病的狗有晕厥和心源性猝死的风险。心肌衰竭和充血性心力衰竭是这种疾病的罕见表现。

狗的健康 - 眼病
2018年，美国食品药品监督管理局（FDA）发布了一份报告，指出某些饮食与没有遗传易感性的犬种发生犬扩张型心肌病（DCM）之间可能存在联系。加州大学戴维斯分校兽医学院的研究人员在2019年初公布了他们自己的研究结果，证实了这种联系，并发现金毛寻回犬中存在特别集中的情况。与饮食有关的DCM与无谷物和/或富含豆类的饮食有关，也与含有奇特原料（如野牛肉或袋鼠肉）的“精品”狗粮有关。在治疗饮食相关的DCM时，除了根据需要进行传统药物治疗外，通常还需要更换食物并补充牛磺酸。

狗的健康 - 眼病
影响狗的其他疾病包括内分泌疾病、免疫介导性疾病和生殖系统疾病。糖尿病、库欣综合征、艾迪生病和甲状腺功能减退症是最常见的内分泌疾病。免疫介导性溶血性贫血是一种破坏性极大的疾病，免疫系统破坏红细胞，导致狗严重贫血。它与疫苗接种和某些药物有关，不过许多病例是特发性的。一种类似但较轻的免疫性疾病是免疫介导性血小板减少症，其特征是免疫系统破坏血小板。临床症状包括瘀伤和瘀点（针尖大小的瘀伤，常见于口腔）。常见的生殖系统疾病包括子宫积脓（子宫因积脓而膨胀）、乳腺肿瘤和良性前列腺增生。

狗的健康 - 眼病
巧克力中的可可含有可可碱，这是一种化学兴奋剂，与咖啡因和茶碱同属甲基黄嘌呤类生物碱。狗无法有效代谢可可碱。如果狗吃了巧克力，可可碱可能会在血液中停留数天，狗可能出现心跳加快、严重腹泻、癫痫发作、心脏病发作、内出血，最终死亡。一盎司（oz）牛奶巧克力含有44 - 55毫克（mg）可可碱，烘焙用巧克力含有393 mg可可碱。使50%的狗死亡的剂量（LD50）为每千克（kg）体重100 – 200 mg，但有些狗只要每千克摄入20 mg就会出现中毒症状。如果狗意外吃了巧克力，尤其是体型较小的狗，应立即联系兽医或动物中毒控制中心；通常建议在摄入后两小时内催吐。治疗方案还包括静脉输液治疗和/或给予活性炭。大型犬对巧克力中毒的易感性较低，但吃下四盎司巧克力后仍可能死亡。

狗的健康 - 葡萄和葡萄干
葡萄和葡萄干可导致狗急性肾衰竭。确切机制尚不清楚，也没有任何方法可以确定某只狗的易感性。对于一只易感的10磅（4.5 kg）重的狗，只要一颗葡萄干就可能中毒，而另一些狗一次吃下多达一磅葡萄或葡萄干也没有不良影响。受影响的狗通常在吃下后几小时内呕吐，三到五天后开始出现肾衰竭的迹象。人们怀疑其中涉及某种霉菌毒素，但在受影响的狗吃下的葡萄或葡萄干中并未发现。水杨酸盐、酒石酸或酒石酸氢钾也被认为可能与此有关。一些狗吃了葡萄和葡萄干后发生肾衰竭的原因尚不清楚。最常见的病理发现是近端肾小管坏死。

狗的健康 - 葡萄和葡萄干
洋葱会导致狗和猫发生溶血性贫血。据报道，烯丙基丙基二硫化物被认为是狗洋葱中毒的主要原因。烷基硫代硫酸盐和正丙基二硫化物也被认为与此有关。硫代硫酸盐的含量不受烹饪或加工的影响。偶尔接触少量通常没有问题，但即使是少量的持续接触也可能构成严重威胁。

狗的健康 - 葡萄和葡萄干
葱属植物（洋葱、青葱、大蒜、韭葱、细香葱等）一般都含有不同含量的有机亚砜类化合物，包括上面提到的两种。这些化学物质赋予了它们特有的辛辣味，但也会对狗和猫的红细胞造成氧化损伤。已有报告称许多这类植物引起中毒，症状从腹泻、呕吐到牙龈苍白和溶血不等。

狗的健康 - 葡萄和葡萄干
肉豆蔻对狗有很强的神经毒性，会引起癫痫发作、震颤和神经系统紊乱，可能致命。肉豆蔻浓郁辛辣的气味对狗有吸引力，可能导致狗吃下致命剂量的这种香料。不应给狗吃蛋酒和其他含有肉豆蔻的食物。

狗的健康 - 葡萄和葡萄干
夏威夷果（澳洲坚果）可引起非致命性的僵硬、震颤、体温过高和腹痛。确切机制尚不清楚。去除接触源后，大多数狗在支持治疗下都能康复。

狗的健康 - 葡萄和葡萄干
啤酒花是一种用于酿造啤酒的植物，可导致狗发生恶性高热，通常会致命。某些品种，如灵缇，似乎对啤酒花毒性特别敏感，但所有狗都应远离啤酒花。即使是少量的啤酒花也可能引发可能致命的反应，即使是酿酒用过的“废”啤酒花也是如此。确切的致病化学物质尚不清楚：目前推测啤酒花中的某种化学物质在狗体内起着解偶联剂的作用。

狗的健康 - 葡萄和葡萄干
摄入酵母（例如未烤的生面团中的酵母）可导致肠梗阻。酵母还会在体内发酵，导致乙醇（酒精）中毒。

狗的健康 - 葡萄和葡萄干
木糖醇是一种代糖，用于口香糖、咀嚼型维生素、糖果、牙膏和其他产品中。虽然一项小型初步研究表明木糖醇可能对狗是安全的，但其他研究显示它有显著的毒性。已有含木糖醇的食品、糖果和口香糖导致狗发生中毒甚至致命性肝损伤的病例。摄入木糖醇可能导致低血糖。

狗的健康 - 葡萄和葡萄干
已知牛油果的叶子、树皮、果皮和果核对包括狗和猫在内的多种动物有害。剂量足够大时可能导致死亡。一般认为果肉对这两种动物没有毒性。

狗的健康 - 葡萄和葡萄干
马桶清洁剂和小便池除臭块有毒。狗可能会试图喝马桶里的水；如果里面有化学清洁剂，就可能带来严重的中毒风险。

狗的健康 - 葡萄和葡萄干
对人、狗和猫同样有毒。由于它有甜味，对狗（和儿童）极其危险。防冻液本身并无毒性，但会经肝脏代谢成乙醇酸盐和草酸盐这两种毒素，引起中毒和呕吐、代谢性酸中毒，最终导致急性肾衰竭，进而引发癫痫发作和死亡。等到观察到临床症状时，肾脏通常已经受损严重，狗无法存活，因此迅速采取行动非常重要。紧急处理包括用阿扑吗啡或稀释的过氧化氢溶液催吐（如果能在摄入后不久进行），但这只能减少吸收量——由于该化合物毒性很高，通常仍必须立即接受兽医治疗。医学治疗可能包括：甲吡唑（首选疗法），它能在体内与毒素竞争；乙醇，它能在肝脏中竞争足够长的时间，使毒素得以排出；活性炭，以进一步减少未消化产物的吸收；以及血液透析，以清除血液中的毒素。在防冻液泄漏或洒出的地方被彻底清理干净之前，不应让狗接近。有些品牌的防冻液用丙二醇代替乙二醇，以降低毒性。另一些则宣传对动物的吸引力较低。

狗的健康 - 葡萄和葡萄干
异丙醇、甲醇（常见于家用产品中）和乙醇（常见于酒精饮料和腐烂的水果中）对狗都有毒。外用酒精中所含异丙醇的毒性是乙醇的两倍；然而，由于甲醇的代谢产物甲酸在体内的处理方式不同，挡风玻璃清洗液中的甲醇对狗的视网膜毒性和神经毒性，不像对人类和灵长类动物那样强。

狗的健康 - 葡萄和葡萄干
乙醇对狗和猫的作用与对人类的作用相似，也会引起醉酒中毒。在支持治疗下不太可能死亡（已知仅有一例死亡）。乙醇也是乙二醇中毒的解毒剂。

狗的健康 - 葡萄和葡萄干
灭鼠剂在家中或车库里很常见。这类抗凝血类毒药的作用原理是耗尽体内储存的维生素K；没有这些储备，血液就无法正常凝固。中毒的临床症状包括精神沉郁、虚弱、呼吸困难、瘀伤以及身体任何部位出血。这些临床症状通常需要3到4天才会出现。血液检查可以证实血液无法正常凝固。如果刚刚吃下毒药（在2到3小时内），应给狗服用阿扑吗啡或过氧化氢以催吐。可以给予活性炭以吸附胃肠道中残留的毒药。然后根据毒药的类型，给狗补充维生素K 3到4周。治疗结束时，应再次检测凝血时间。这类病例的预后良好。然而，如果狗已经出现中毒症状，再试图从体内清除毒药就为时已晚。此时要输注全血或血浆，以治疗贫血并尽力控制出血，同时也给予维生素K。这类病例的预后不良。

狗的健康 - 葡萄和葡萄干
含胆钙化醇的灭鼠药会导致狗发生高钙血症和高磷血症。临床症状包括精神沉郁、食欲不振、吐血、虚弱和休克。对于近期接触的病例，治疗方法同上。发生高钙血症时（可能需要1到2周），治疗方法是静脉输液（生理盐水）、利尿剂、皮质类固醇和降钙素。狗的病情稳定后，长期预后良好。

狗的健康 - 葡萄和葡萄干
由于其中含有四聚乙醛，摄入后可引起焦虑、肌肉抽搐、癫痫发作、心跳加快、瞳孔散大、流涎过多、呕吐、腹泻和高烧。治疗包括洗胃、静脉输液和/或给予活性炭。

狗的健康 - 葡萄和葡萄干
止痛药中毒很常见。阿司匹林、扑热息痛/对乙酰氨基酚（泰诺）、布洛芬（Advil）和萘普生（Aleve）都可能使狗出现严重的临床症状，包括吐血、腹泻和腹痛。具体来说，阿司匹林可引起代谢性酸中毒和出血性疾病，对乙酰氨基酚在高剂量时可引起肝病（中毒剂量为每千克体重150 mg），布洛芬可引起肾病，萘普生可引起胃溃疡，而胃溃疡可能穿孔。治疗取决于临床症状，通常包括催吐、洗胃、静脉输液利尿和支持治疗。对乙酰氨基酚中毒的解毒剂是N-乙酰半胱氨酸。

狗的健康 - 公共卫生风险
大多数影响狗或人的疾病不会在这两个物种之间传播。能从动物传给人的疾病称为人兽共患病。一种众所周知的人兽共患病是狂犬病，这是一种通过咬伤传播的病毒感染。一种常见的细菌性人兽共患病是钩端螺旋体病，通过尿液传播。一些最重要的人兽共患病是寄生虫病。通过接触粪便传播的人兽共患肠道寄生虫包括犬弓首线虫（Toxocara canis，即犬蛔虫）和钩虫，前者可引起弓首线虫病、内脏幼虫移行症和眼幼虫移行症，后者可引起皮肤幼虫移行症。人兽共患的皮肤寄生虫包括由疥螨（Sarcoptes scabiei）引起的疥疮。最常见的人兽共患真菌病是癣病，在这种情况下由犬小孢子菌（Microsporum canis）引起。

狗的健康 - 疫苗接种
疫苗接种是一项重要的动物健康预防措施。建议狗接种的具体疫苗因地理位置、环境、旅行史以及狗经常参与的活动而异。在美国，无论上述因素如何，通常都强烈建议狗接种狂犬病、犬细小病毒、犬瘟热和犬传染性肝炎疫苗（使用2型犬腺病毒以避免不良反应）。是否接种其他疾病的疫苗，包括钩端螺旋体病、莱姆病、支气管败血波氏杆菌、副流感病毒和犬冠状病毒，应由主人和兽医根据该狗的具体因素共同决定。

狗的健康 - 牙科
牙病是狗最常见的疾病之一。牙菌斑以及随后形成的牙结石积聚会导致牙龈炎，进而导致牙周炎（牙龈病）。牙周炎会导致牙齿与骨骼之间的附着丧失，以及牙齿脱落。预防措施包括刷牙、提供合适的饮食（避免罐头和其他软质食物，并提供洁齿咀嚼零食），以及洗牙和抛光。狗很少有龋齿。

狗的健康 - 心丝虫、跳蚤或蜱预防药
每月一次的外用产品和口服药物是最常用于杀灭和预防心丝虫感染以及跳蚤或蜱侵扰的产品。

狗的健康 - 营养与肥胖
一般不建议给狗喂剩饭剩菜，至少不应过量。与人类一样，狗的饮食必须由适当搭配的营养素、碳水化合物和蛋白质组成，为它们提供所需的矿物质和维生素。狗能从其天然的正常饮食中获得充足而适当的营养；野狗和流浪狗通常能从整只猎物和生肉组成的饮食中获得所需的全部营养。此外，人类的饮食对狗来说并不理想：对于狗这样的兼性食肉动物来说，“均衡”饮食的概念与杂食性的人类不同。狗通常会把喂给它们的剩菜和零食全部吃掉：往往吃得太多。虽然并非所有人类美食对狗都有急性毒性（见上文），但许多食物对狗造成的长期不良后果与对人类相同。

狗的健康 - 营养与肥胖
在西方国家，肥胖是狗身上越来越常见的问题。与人类一样，肥胖会给狗带来许多健康问题（尽管与人类相比，狗远不容易出现肥胖常见的心脏和动脉方面的后果）。根据发表在《兽医内科学杂志》上的一项研究，狗的肥胖患病率在22%到40%之间。

狗的健康 - 营养与肥胖
狗零食常被用来奖励宠物，或者只是给它们一根骨头啃，这能锻炼它们的颌部肌肉，并有助于保持牙齿清洁。虽然狗零食对狗的牙齿有很大好处，但如果喂得过多，尤其是人吃剩的饭菜，也可能引发肥胖等问题。

狗的健康 - 营养与肥胖
所喂食物的类型直接影响狗超重的倾向。剩饭剩菜、零食，甚至优质的高能量狗粮都可能导致肥胖。因此，密切控制狗吃零食的数量非常重要，特别是在狗的活动量减少时。狗零食更有可能与老年犬的肥胖有关，因为老年犬不太活跃，运动较少。活跃的狗需要并消耗更多的热量。

狗的健康 - 食粪癖
有些狗可能会试图吃粪便。有些狗吃自己或其他狗的粪便；另一些似乎更喜欢猫的粪便（由于猫科动物的消化系统特点，猫粪蛋白质含量高，野外的许多动物都会吃）。如果粪便中含有病原体或寄生虫，或含有排出的药物，就可能对狗有害。

狗的健康 - 食粪癖
目前尚不清楚是否应该给狗补充维生素和补充剂——兽医们的意见分歧很大。有些人认为维生素和补充剂是必要的，能够改善狗的健康；另一些人则认为它们没有必要，甚至可能对狗有害。根据美国食品药品监督管理局（FDA）的说法，仅靠商业加工的狗粮，狗就能获得全面均衡的饮食。给狗喂自制饮食的宠物主人可以额外添加维生素和补充剂。

狗的健康 - 食粪癖
在美国，大约10%到30%的狗服用营养补充剂。2006年对美国宠物主人进行的一项调查发现，最常用的补充剂是复合维生素和软骨保护剂。

狗的健康 - 食粪癖
维生素过量可能对狗有害。例如，钙过量会引起骨骼问题，特别是在大型犬中。过量补充维生素A和D会导致狗维生素中毒。维生素A过量会引起脱水、关节疼痛，还可能损害血管；而维生素D过多则会引起肌肉萎缩、食欲不振和许多其他健康问题。

狗的健康 - 卵巢子宫切除与去势
卵巢子宫切除（雌性）和去势（雄性）是指给动物绝育，通常是切除雄性的睾丸或雌性的卵巢和子宫，以消除繁殖能力并降低性欲。已知去势能减少公犬的攻击行为，但研究表明，卵巢子宫切除有时会增加母犬的攻击行为。

狗的健康 - 卵巢子宫切除与去势
美国的动物管控机构和美国防止虐待动物协会（ASPCA）建议，不打算继续繁殖的狗应进行绝育，以免生下不想要的幼犬。

狗的健康 - 卵巢子宫切除与去势
由于一些国家狗的数量过多，流浪狗生下的或意外交配生下的幼犬往往最终在动物收容所被杀死。绝育还可以降低乳腺癌等激素驱动疾病的风险，并减少不良的激素驱动行为。然而，术后某些健康问题更容易出现，如母犬尿失禁和公犬前列腺癌。不过，绝育所涉及的激素变化可能会在一定程度上改变动物的性格，而且有些人反对卵巢子宫切除和去势，因为绝育可以在不切除器官的情况下进行。

狗的健康 - 卵巢子宫切除与去势
母犬在做卵巢子宫切除术之前，既不必经历发情周期，也不必生过幼犬；同样，公犬在去势之前也不需要有交配经历。

狗的健康 - 卵巢子宫切除与去势
如果在第一次发情周期之前不做绝育，母猫和母犬患乳腺肿瘤的可能性要高出七倍。普通市售宠物食品中膳食雌激素含量高，可能是乳腺癌发生的促成因素，特别是当这些外源性雌激素叠加到身体自身产生的正常雌激素之上时。已发现含有大豆或大豆成分的狗粮含有植物雌激素，其含量在长期摄入时可能产生生物学效应。
