# 语料来源说明

本语料库的所有文件均取自中文维基百科，依 CC BY-SA 4.0 授权
（https://creativecommons.org/licenses/by-sa/4.0/）发布。
文字通过 MediaWiki API 取得，去除标记后重新排版，使每个段落前都标上
条目名称与章节名称。仅保留与动物健康相关的章节。

有些主题中文维基百科完全没有收录。这些主题将英文维基百科条目的文字译成了中文；
译文仍注明出自下方链接的英文原条目，并采用相同授权发布。这样助理就能以任何语言
回答同样的问题。

基于同样的理由，凡有英文对应文件者，皆在中文内容之后附上对应英文文字的完整中文译文，并注明出自英文原条目。
整个语料库均为中文（中文原文或译文），英文版本的信息一项不缺。
